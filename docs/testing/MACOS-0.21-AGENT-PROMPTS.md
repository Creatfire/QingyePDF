# 给 8 个测试 agent 的任务说明

每段是一条完整的任务，复制到一个新的 agent 会话（例如 MiniMax Code 的新会话）里，8 个会话同时运行。测试步骤、规则和报告格式都在 [macOS 版并行测试文档](MACOS-0.21-TEST.md)。各 agent 需要能在终端执行命令、读写本机文件；A8 另外需要能操作屏幕（鼠标、键盘、截图）。

所有任务共用的开头：

> 你是青页 PDF macOS 版的测试员，只做测试和记录，不修改源码。项目在 `/Volumes/RC10/QingyePDF/QingyePDF-v0.20.0`。先完整阅读 `docs/testing/MACOS-0.21-TEST.md` 的第 0–3 节，严格遵守第 1 节的并行规则（同时还有 7 个 agent 在这台电脑上测试）。然后执行你的任务卡，每一步都记录结果和证据，最后按第 3 节的格式把报告写到 `test-output/agents/<你的编号>/report.md`。遇到失败先确认能重现，再记录重现命令；不要跳过步骤，不要自行修复代码。全部完成后执行 `Q stop` 关闭自己的实例，并回复报告路径和一句话总结（通过多少项、失败多少项、阻塞多少项）。

---

## A1

（共用开头）你的编号是 **A1**，端口 **9301**，任务卡是第 4 节的“A1 · 构建产物与自动测试”。你不需要启动交互实例，但第 2 节里的环境变量（`AGENT`、`D`、`F`、`Q`）照样设置。A1-10 完成后，在 `test-output/agents/A1/STATUS` 里写一行 `冒烟完成`，A8 会等这个文件。

## A2

（共用开头）你的编号是 **A2**，端口 **9302**，任务卡是“A2 · 工具栏第一、二期”。A2-03 只打开打印界面再按 Esc 取消，不要实际打印。

## A3

（共用开头）你的编号是 **A3**，端口 **9303**，任务卡是“A3 · 工具中心、固定与停靠”。A3-14 要先停止再用同一个编号重新启动，配置目录会保留。

## A4

（共用开头）你的编号是 **A4**，端口 **9304**，任务卡是“A4 · 命令面板、快捷键、窄宽度与多语言”。测完多语言后把语言切回 `zh-CN`。

## A5

（共用开头）你的编号是 **A5**，端口 **9305**，任务卡是“A5 · PDF 处理工具结果正确性”。每个工具的输出都要用 PyMuPDF（`.backend-build/bin/python`）或对应的 Python 库实际读一遍再判定，不能只看有没有生成文件。

## A6

（共用开头）你的编号是 **A6**，端口 **9306**，任务卡是“A6 · 编辑、批注、页面管理、撤销与保存”。A6-11 用 `kill -9` 时只杀 `test-output/agents/A6/session.json` 里记录的那个 pid。

## A7

（共用开头）你的编号是 **A7**，端口 **9307**，任务卡是“A7 · Office、Markdown、转换中心、笔记模式与全库搜索”。A7-09、A7-11 不要点任何联网查询或配置真实的 AI 服务。

## A8

（共用开头）你的编号是 **A8**，端口 **9308**，任务卡是“A8 · 系统集成与人工交互”。只有你可以操作真实的鼠标、键盘和系统界面。先等 `test-output/agents/A1/STATUS` 出现 `冒烟完成` 再开始需要屏幕的步骤，等待期间可以先读文档、做备份。开始前备份 `~/Library/Application Support/QingyePDF`（存在的话），结束后恢复；系统外观改过要改回去；不要实际打印；不要删除用户的任何文件。
