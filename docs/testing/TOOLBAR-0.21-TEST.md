## 2. 自动测试

在 Windows 10 / 11 x64 上按 [构建与发布](../development/BUILDING.md) 准备好依赖后运行：

```powershell
npm run verify
node scripts/ci-smoke.cjs
npm run dist
node scripts/ci-smoke.cjs --packaged
```

重点看这几个文件：

- `test/toolbar021.test.mjs`：工具表的完整性（每个工具有分组、图标、打开方式；工具箱表单里的每个操作都能从工具表打开）、搜索排序、固定与最近使用的上限、工具栏标记里的菜单 id、新文字的四种译文。
- `test/design-smoke.cjs`：打开“工具 ▾”“编辑 ▾”“保存 ▾”，工具中心首页、搜索“水印”、固定到工具栏、命令面板搜“打印”、920 px 宽度不出现“更多”、工具栏变窄后按钮移进“更多”。截图写在 `test-output/ci/smoke/test-output/toolbar-*.png`。
- `test/usability-smoke.cjs`：经“工具 ▾ → 全部工具…”打开、关闭工具中心 3 次。

## 3. 手动测试

准备两份以上 PDF（其中一份为扫描件）、一份 Markdown。每项在浅色和深色、Windows 和 MacOS 两种界面风格下各看一次。

### 3.1 工具栏（第一期）

| 编号 | 步骤 | 预期 |
|---|---|---|
| T1 | 打开 PDF，点“打印”；再按 Ctrl+P | 两种方式都弹出打印对话框；首页、未打开文档时“打印”不可用 |
| T2 | 点“保存”旁的小箭头 | 菜单有“另存为…”“文档属性”；另存为与 Ctrl+Shift+S 结果相同；文档属性弹出 PDF 属性窗口 |
| T3 | 做一次页面重排后点“重做”旁的小箭头 | 列出最近的修改（最多 5 条），点任意一条或“编辑历史…”打开编辑历史对话框 |
| T4 | 工具处理进行中查看“保存 ▾” | 保存、另存为都不可用，鼠标提示“本地处理正在进行” |
| T5 | “视图 ▾”→“与另一文档并排比较…”；只开一份 PDF 时再看 | 两份 PDF 时进入并排比较；只有一份时该项不可用 |
| T6 | “视图 ▾”→“在新窗口中打开”，先在有未保存批注时试一次 | 有未保存批注时提示先保存；保存后在新窗口打开 |

### 3.2 批注、编辑与指针（第二期）

| 编号 | 步骤 | 预期 |
|---|---|---|
| E1 | 点“抓手”，拖动页面；再点“选择” | 抓手可拖动页面，按钮高亮切换；选择恢复文字选择 |
| E2 | 页面编辑进行中点“抓手” | 状态栏提示先应用或取消页面编辑 |
| E3 | 打开“批注 ▾” | 顶部说明“标记与评论，不改动原文”；含高亮、绘制、文本框、图片、签名、评论、图形和“下划线 / 删除线（区域）…”；后者打开对应工具 |
| E4 | 打开“编辑 ▾”，逐项点击 | 添加文字、文字印章、图片印章、图形、替换区域内原文、全页水印进入页面编辑；永久涂黑、编辑目录打开工具面板；页面管理打开缩略图网格 |
| E5 | 页面编辑中再开“编辑 ▾” | 多出“取消当前页面编辑”，点击后退出编辑 |
| E6 | 文字重排阅读时打开“编辑 ▾” | 各项不可用 |
| E7 | 右键菜单 | 与 0.20.0 相同，仍可用批注、页面内容、页面管理、打印、文档属性 |

### 3.3 工具 ▾ 与工具中心（第二、三期）

| 编号 | 步骤 | 预期 |
|---|---|---|
| C1 | 未固定任何工具时打开“工具 ▾” | “常用”下是压缩 PDF、文字识别 OCR、导出为 Word / Excel / PPT、合并与拆分、密码与权限；底部“全部工具…” |
| C2 | 用过两三个工具后再开“工具 ▾” | 出现“最近使用”，不重复常用里的项 |
| C3 | Ctrl+Shift+T，或“全部工具…” | 打开工具中心首页：搜索框、最近使用、六组卡片；不显示替换原文、单个图形、区域下划线、编辑目录 |
| C4 | 搜索“水印”“密码”“拆分”“word”，按 Enter | 结果按名称优先排序；Enter 打开第一个结果；无结果时显示“没有找到匹配的工具。” |
| C5 | 点卡片打开工具，再点“‹ 全部工具” | 进入该工具的设置，标题为工具名；返回首页 |
| C6 | 点“导出为图片或文本” | 导出格式预选 PNG，DPI 字段可见 |

## 4. 已知问题与未测范围

1. **全屏检查（已查明，不是产品问题）。** 在 macOS 上 `test/smoke.cjs` 的全屏检查曾在本分支失败。原因是检查固定只等 350 ms，而 macOS 的全屏动画进入和退出都超过 1 秒：改为最多等 4 秒后，进入和用 Esc 退出都正常，整个 `smoke` 套件通过。检查已改为等待状态变化（`fullScreenIs`）。
2. **macOS 上不适用的旧检查。** `smoke` 套件里 `usability-smoke.cjs` 的原生右键菜单复制 / 粘贴（窗口在后台时系统剪贴板不更新）和 `enhancement-smoke.cjs` 的 Ctrl+C 复制（Mac 上复制是 ⌘C）在本机失败，未改动的代码也一样。它们写给 Windows，Windows 上应能通过。
3. 停靠的工具面板里，框选区域的工具仍使用面板内的预览图，还不能直接在文档页面上框选。
4. 桌面窗口最小宽度是 920 px，在这个宽度下通常不需要“更多”；只有固定工具较多时才会出现。
5. 没有“导出副本”：现有代码没有保存副本的接口，所以“保存 ▾”只有另存为和文档属性。
6. 命令面板用 Ctrl+Shift+P，不是示意图里的 Ctrl+K：Markdown 编辑器里 Ctrl+K 是插入链接。
7. 未测：真实打印机、安装包、安卓与 macOS 打包、高对比度和屏幕阅读器、新译文的母语校对。
