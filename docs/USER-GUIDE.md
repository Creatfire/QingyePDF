# 青页 PDF 使用说明

**当前版本：Windows 0.17.0，Android 与 macOS 0.13.0。** Windows 下载 `QingyePDF-0.17.0-win-x64.exe`，设置 → 常规中可独立选择“界面皮肤”和“首页样式”。macOS 用户请先看 [MACOS.md](MACOS.md)（安装、快捷键对照）；安卓版的触屏操作见应用内“更多 → 使用帮助”和 [mobile/README.md](../mobile/README.md)。本文的快捷键按 Windows 书写，Mac 上把 Ctrl 换成 ⌘、Alt 换成 ⌥。

**0.11.0：** 笔记模式有了双向关联（摘录带原文位置、点链接回到原文并高亮、批注一键同步、滚动联动、框选区域摘录），新增全库搜索和引用信息 / BibTeX。构建与验证范围见 [HANDOFF.md](../HANDOFF.md)，历史交接文档在 [docs/history](history/)。

## 笔记与原文的双向关联（0.11.0）

在笔记模式（PDF + Markdown）下：

- **摘录带位置**：选中文字后“摘录到笔记”（右键或 Ctrl+Shift+E），链接里除了页码还记录这段文字在页面上的位置。
- **回到原文**：点击笔记里的摘录链接，PDF 跳到那一页并用绿色框标出原文约 2.6 秒。旧版只带页码的链接仍然可用。
- **框选区域**：公式、图表、表格用文字摘不了时，按 Ctrl+Shift+U（或右键“框选区域摘录到笔记”、分隔条上的裁剪按钮），在页面上拖出一个框；这块区域按约 1600 像素宽重新渲染成 PNG，保存到笔记旁的图片文件夹并插入笔记，下面附一条回到该区域的链接。Esc 取消。笔记必须先保存到磁盘（未保存时会先弹出保存对话框）。
- **同步批注**：分隔条上的批注按钮或笔记模式菜单里的“同步 PDF 批注到笔记”，把 PDF 的全部批注（高亮的原文、评论内容、类型、页码）追加到笔记末尾；笔记里已经有的批注不会重复添加，所以可以反复执行。
- **滚动联动**：阅读 PDF 翻页时，笔记自动滚到该页的第一条摘录；这一页没有摘录时停在之前最近一页的最后一条。只在 PDF 一侧获得焦点时生效，在笔记里打字不会被打断。分隔条上的链接按钮或菜单可以关闭，设置会被记住。
- **菜单**：进入笔记模式后，再点标题栏的笔记模式按钮会显示以上命令；Ctrl+\\ 仍然直接退出。

限制：滚动联动是 PDF → 笔记单向；多栏排版中跨栏的选区，记录的是覆盖选区的一个矩形；区域图片不包含尚未保存的批注编辑框。

## 全库搜索（0.11.0）

标题栏的放大镜按钮或 Ctrl+Shift+F：在最近列表里所有 PDF 和 Markdown 的**内容**中搜索（首页的最近文件搜索框里按 Enter 也会进入）。

- 多个词用空格隔开，要求出现在同一页（PDF）或同一段（Markdown）；用引号搜索完整短语。不区分大小写。
- 结果按文档分组，显示页码 / 行号和上下文；点击后打开文档并跳到那一页（PDF 会高亮该词）或那一段。
- 第一次使用时为每个 PDF 读取文字并建立索引，之后只有大小或修改时间变化的文件会重新读取。索引保存在本机用户数据目录的 `library-index` 文件夹，不联网；从最近列表移除的文件，其索引会被删除。“重建索引”可以全部重来。
- 限制：扫描版 PDF 需要先在工具箱里做 OCR 并保存才有文字；有打开密码的 PDF、超过 300 MB 的文件不进入索引；搜索范围是最近列表（上限由最近列表决定），不是整个磁盘。

## 引用信息与 BibTeX（0.11.0）

PDF 页面右键“引用信息 / BibTeX…”，或笔记模式菜单中的同名命令。

- **本机识别**：从 PDF 元数据和前两页文字里找 DOI、arXiv 编号、标题（第一页上部最大的文字）、作者和年份。识别结果只是起点，可以逐项修改。
- **联网补全（可选）**：点击“联网补全”时，只把 DOI 发送到 doi.org 取回正式的题录；不点就不会联网。
- **输出**：BibTeX（可复制）、GB/T 7714 或 APA 格式的引用（点击引用行切换）、在笔记模式下“插入到笔记”（附带 `[@引用键]`，可配合 Pandoc 的 citeproc）。
- **文献库**：每个文档填写过的引用信息保存在本机，“导出文献库…”把全部条目写成一个 `.bib` 文件，重复的引用键会自动加后缀。

## 笔记模式（0.10.0）

把两个已打开的文档左右并排：PDF + Markdown、Markdown + Markdown、PDF + PDF 都可以。两侧仍是普通标签，保存、撤销、草稿恢复不变。

- **进入**：标题栏的“笔记模式”按钮（Ctrl+\）选择右侧文档——新建一份笔记、任一已打开文档、上次搭配的文档或打开其他文件；也可以右键标签选择“在右侧 / 左侧打开”。再按一次按钮或 Ctrl+\ 退出，关闭任一侧文档也会退出。
- **焦点**：最后点击的一侧是当前文档（顶部有一条强调色线），保存、撤销、查找等快捷键作用于它。PDF 与 Markdown 搭配时，PDF 工具栏、搜索 / 大纲侧栏始终服务于那份 PDF。
- **窗格**：拖动中间的分隔条调整宽度（25%–75%，双击还原），悬停分隔条可以交换左右或退出。点击其他标签时，新文档替换同类型的那一侧；两侧同类型时替换当前一侧。
- **摘录**：在 PDF 中选中文字，右键“摘录到笔记”或按 Ctrl+Shift+E，引用和带页码的原文链接会插入到旁边 Markdown 的光标处。点击链接在另一侧原地定位，不会切走标签。批注侧栏的“将选中批注整理为笔记”在笔记模式下直接写入旁边的笔记。
- **AI**：AI 面板同时显示两份文档；文档工具可按 `document_id` 读取任一侧，`list_documents` 会说明左右各是哪一份。写入 Markdown 仍先显示差异确认；新增 `annotate_pdf` 工具，可以按原文片段给 PDF 加高亮、下划线或删除线并附评论，作为一次可撤销的修改，不会自动保存。AI 不能修改 PDF 正文。
- **限制**：同一个文档不能同时放在两侧；只支持左右两个窗格；跨行的 AI 批注是覆盖这些行的一个矩形；笔记模式状态不随会话恢复，只记住“哪份文档上次和哪份搭配”。安卓版不提供笔记模式。

## 界面风格：Windows / MacOS（0.9.2）

设置 → 常规 → **界面风格** 提供两种外观，点击预览卡片即可选择，重启青页后生效（提示条中的“立即重启”会先按正常流程关闭文档——有未保存的修改会先询问——然后自动重新打开刚才的标签）：

- **Windows**（默认）：与 0.9.1 相同，右上角为系统原生的最小化 / 最大化 / 关闭按钮（支持 Windows 11 贴靠布局）。
- **MacOS**：左上角红绿灯（关闭 / 最小化 / 最大化，悬停显示 × − 与箭头图标，窗口失去焦点时变灰），标题栏与工具栏一体、圆角标签与按钮、更大的窗口圆角感，菜单、弹出层、对话框、翻页面板等使用毛玻璃（背景模糊 + 半透明），配色改为 macOS 式的中性灰，保留青页绿色强调色；浅色 / 深色都适用。
- **窗口毛玻璃**（仅 MacOS 风格，需 Windows 11 22H2 或更高版本，默认关闭）：窗口使用系统亚克力材质，标题栏、侧栏和首页透出模糊的桌面背景；旧系统上该开关不可用，仍使用应用内毛玻璃。

说明：MacOS 风格下窗口按钮由青页绘制，双击标题栏空白处仍可最大化 / 还原，但不再显示 Windows 11 的贴靠布局弹出框（可用 Win + ↑ / ← / → 或 Win + Z）。窗口外框圆角由系统决定：Windows 11 自动圆角，Windows 10 为直角。

## AI 协作（0.9.1）

PDF 与 Markdown 文档右侧可以打开 **AI 协作** 面板（PDF 工具栏“AI”按钮、Markdown 顶栏的星形按钮，或 Ctrl+Shift+A）。面板参考了 Open WebUI 的聊天体验（模型切换、流式输出、停止 / 重新生成、“/” 提示词预设、工具调用过程、历史对话），但围绕“正在看的文档”工作：

- **模型连接**：设置 → AI 协作。内置 OpenAI、DeepSeek、通义千问、Kimi、智谱、SiliconFlow、OpenRouter、Anthropic、Ollama、LM Studio 预设，也可填写任意 OpenAI 兼容地址。支持**导入** Open WebUI 的连接配置（`openai.api_base_urls / api_keys`、`ollama.base_urls`）、`.env`（`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`ANTHROPIC_API_KEY`、`OLLAMA_HOST` 等）、`{"base_url","api_key"}` JSON、青页导出的 JSON，或“地址 空格 Key”一行；可导出（默认不含 Key）。
- **读懂文档**：模型通过文档工具按需读取页面、搜索全文、查看目录与选中内容，回答可使用工具返回的可点击页码 / 行引用；点击定位原文，工具卡片可查看实际读取位置和截断提示；模型不支持工具调用时自动改为随问题发送文档开头部分（上限可调）。选中文字后提问会自动附带选中内容。
- **写回文档**：回答可以复制、插入到 Markdown 光标处（有选中内容时替换）、另存为新的 Markdown 标签；模型也可以在你同意后直接写入 Markdown。所有写入都不会自动保存，可 Ctrl+Z 撤销。PDF 不允许 AI 直接修改。
- **本地 AI 接口**（默认关闭）：在设置中开启后，青页在 `http://127.0.0.1:17654` 提供 OpenAPI 3.1 文档接口（`/openapi.json`），外部 AI 工具——例如 Open WebUI 的“工具服务器”、智能体或脚本——可以列出、读取、搜索、跳转已打开的文档，写入需在青页中确认（可改为直接允许）。只监听本机回环地址，每次请求须带 `Authorization: Bearer <令牌>`，并校验 Host 头以防 DNS 重绑定。

隐私：只有在你配置了 AI 连接并发送消息时，才会把问题和模型读取的文档片段发送到你配置的服务；API Key 用 Windows 数据保护（Electron safeStorage）加密保存在本机 `ai-config.json`，界面与渲染进程都拿不到明文 Key；AI 请求走独立的网络会话，其余界面仍然阻止一切网络访问。

## 文档转换（0.9.0）

首页“文档转换”或标题栏“转换”打开文档转换中心。内置官方 Pandoc 3.12，无需用户单独安装；直接提供原版 51 个输入 / 76 个输出格式入口、模板、Defaults、引用排版和 Lua 过滤器。PDF 默认可选青页内置排版，无需 TeX；Pandoc 外部 PDF 引擎仍需对应程序。详情见 [CONVERSION.md](CONVERSION.md)。

独立重写引擎的旧路线已停止，本版复用原版引擎。原有 PDF 阅读、编辑、OCR 和 Markdown 工作流保留。

## 使用

双击 `QingyePDF-0.12.0-win-x64.exe` 运行，不需要安装 Node.js、Python 或登录。OCR、字体和处理引擎随程序提供。便携程序只在首次运行或版本变化时解压；后续复用 `%LOCALAPPDATA%\QingyePDF\runtime` 下按版本和包哈希隔离的运行缓存。首次运行结束会显示一次性说明；较慢的电脑或杀毒软件实时扫描时首次解压可能花十几秒，属正常现象。删除对应缓存目录可让程序重新解压；请先关闭自己的测试实例并确认没有其他实例使用该缓存。目标平台为 Windows 10/11 x64，目前独立验收覆盖 Windows 11 x64、单显示器100% DPI；其他配置尚需实测。可把 PDF 文件拖入窗口，或用“打开文档”选择多个文件。本次仅交付便携版，没有 0.9.3 Setup 安装包；源码提供安装包构建入口，不能把旧版安装包当作本版本。

源码与依赖源码分别为 `QingyePDF-0.12.0-source.zip`、`QingyePDF-0.12.0-dependency-source.zip`，文件校验见 `SHA256-0.12.0.json`。许可文本见 `LICENSE-0.9.4.txt`（源码中为 `LICENSE`）。带旧版本号的文件与记录属于历史归档，运行和测试请以本页入口为准。

## Markdown 阅读与编辑

打开 `.md` / `.markdown` 文件（打开对话框、拖入窗口或文件关联），或按 Ctrl+N 新建。Markdown 标签使用独立界面（0.8）：不显示 PDF 工具栏，顶部是 Markdown 菜单栏，右侧依次为查找、侧边栏、**阅读 / 编辑 / 源码** 三种视图切换、命令面板与保存按钮；底部状态栏显示操作提示、字数与光标位置（阅读模式下为预计阅读时间）、编码与换行符。

- 首页：打开文件、新建 Markdown、恢复上次标签；“最近打开”列表可按类型与名称筛选、从列表移除；右侧为常用 PDF 工具与示例（PDF 示例为 7 页功能导览，可直接练习批注与文字识别）。
- **设置**（0.8.2，标题栏右侧齿轮，位于帮助左边）：显示语言（跟随系统 / 简体中文 / 繁體中文 / English / 日本語 / 한국어，即时切换，无需重启）、界面主题、界面风格（Windows / MacOS，0.9.2）、启动时恢复上次标签、PDF 默认缩放与是否回到上次位置、Markdown 阅读模式 / 自动保存 / 文档主题、**默认打开方式**（把青页注册为 PDF 与 Markdown 的打开程序，再在 Windows 弹出的“选择打开方式”或“默认应用”设置中确认）、清除最近列表、打开数据文件夹、关于。
- **阅读**：只看排版好的文档，不会误改；单击链接直接打开；双击正文或按 E 回到编辑（Ctrl+Shift+R 切换）。可在“偏好设置 → 外观 → 界面”中设为打开已有文件时默认进入阅读模式。
- **编辑**：文档按块渲染；单击任意段落即进入编辑，光标所在块显示带样式的 Markdown 语法，离开后立即渲染。
- **源码**：纯文本编辑整篇 Markdown（Ctrl+/）。
- 文档顶部细线显示阅读进度；查找与替换为 Ctrl+F / Ctrl+H。

**Typora 式功能集**：顶部菜单栏（文件 / 编辑 / 段落 / 格式 / 视图 / 主题 / 帮助）与命令面板（Ctrl+Shift+P）覆盖全部命令，快捷键可在“偏好设置 → 快捷键”修改；支持高亮、上下标、表情、脚注、[TOC]、警告框，表格与图片快捷工具条，专注（F8）/ 打字机（F9）/ 阅读模式，大纲与文件树侧栏（最近文件在“文件”菜单与 Ctrl+P 快速打开中），六套主题与自定义 CSS，多种导出格式（PDF / HTML / Word / ePub / LaTeX / RTF / 图片；使用内置 Pandoc 引擎还可导出 ODT、RST、PPTX 等并导入 docx 等）与版本历史。功能参照 Typora 的帮助文档独立实现，不含 Typora 代码。完整清单与已知限制见 CHANGELOG。

- 常用快捷键：Ctrl+B / I 加粗斜体，Ctrl+K 链接，Ctrl+Shift+` 行内代码，Alt+Shift+5 删除线，Ctrl+1–6 标题、Ctrl+0 正文，Ctrl+T 表格，Ctrl+Shift+K 代码块，Ctrl+Shift+M 公式块，Ctrl+Shift+I 图片，Ctrl+Shift+Q 引用，Ctrl+Shift+[ / ] 有序 / 无序列表，Ctrl+Shift+X 任务列表，Ctrl+Enter 在块后新建段落，F3 查找下一个。
- 保存逐字写回原文，保留 BOM 与换行符（CRLF/LF）；GBK 等旧编码打开时提示，保存为 UTF-8。其他程序修改文件后：没有未保存修改时自动载入（Ctrl+Z 可撤回），有未保存修改时提示，保存前再次确认覆盖或另存为。
- 粘贴或拖入的图片保存到文档旁的 `assets` 文件夹（需先保存文档）；相对路径的图片与 `.md` / `.pdf` 链接按文档位置解析。网络图片不加载（离线）。
- ```mermaid 代码块渲染为图表（流程图、时序图、状态图、类图、甘特图等，随浅色/深色主题配色），过宽的图表自动缩放到页面宽度，悬停可切换“原始大小”；单击图表编辑源码，下方实时预览。
- 表格可直接编辑单元格与增删行列、粘贴 Excel TSV；仍保留表格源码入口。HTML 块经过安全过滤后渲染。

## 0.7.0 图像锐化与扫描文字选择

- **PDF锐化**：工具箱 → 处理 → PDF图像锐化，选择轻度、标准或较强。可应用到当前文档并撤销，或处理并导出副本。作用于整份文档的内嵌图像，保留文字、目录、页面尺寸/旋转及批注；矢量内容保持原样。共享图像只处理一次，暂不提供按页锐化。图像超过4000万像素会提示先降低尺寸。锐化增强边缘，不能恢复丢失的细节；较强档可能放大噪点、产生光晕，输出可能变大。
- **扫描件文字选择**：点击顶部“文本选择”，或阅读器中的文本选择工具；在默认文字选择模式拖选扫描页时也会自动识别。当前页缺少文字层时，本地识别中英文并添加透明文字层，原扫描图不重新采样，页面外观保持。完成后可拖选、复制和搜索当前已识别页；保存可保留文字层，撤销可移除。只识别使用到的页面，其他未识别扫描页仍需切换后识别，搜索不会自动对全文件做OCR。
- 识别过程显示进度，可点“取消识别”；文字层正在更新时短暂禁用取消，避免更新中断。已有文字层不重复识别。切换到手形工具或批注工具时不自动OCR。重排文字视图请先退出；未应用页面编辑应先应用或取消。
- 新功能全部离线，复用随包中英文字库。OCR结果受清晰度、字体和方向影响，可能有错字或字间空格，请复核复制文本；加密扫描件若自动识别无法取得密码，可从工具箱OCR填写密码处理副本。工具箱的旧OCR入口仍按200DPI重建识别页，与“文本选择”的保留原图文字层方式不同。

## 页面编辑与撤销

- “页面编辑”在阅读页上添加文字、替换原文、放置文字或图片印章、水印与图形；拖动虚线框移动，拖动右下角改变大小，文字字号随缩放调整。改变参数后约 650 ms 生成实际 PDF 预览；大型文件或复杂字体可能需要更久。临时阅读旋转会重置到 0°，页面本身的旋转保留。应用前不修改文档，应用后可撤销，保存才写入文件。
- 文字水印可一次应用到全部页。预览只渲染当前页；相同相对位置应用到所有页，尺寸各异的页面请复核。添加文字不删除原文；“替换区域原文”会删除框选区域内原文字。
- 页面右键菜单提供文字、印章、水印、图形、自由绘制、高亮、签名、旋转、删除、排序、目录与撤销/重做。选中的正文输入框保留原生文本编辑菜单。
- 页面侧栏的拖动排序草稿有独立撤销/重做。“应用排序”、删除、旋转修改当前文档并支持全局撤销；提取和导出排序仍生成副本。目录编辑器也提供草稿撤销/重做，工具箱“应用到当前文档”把目录等修改纳入全局文档历史。
- 顶部撤销/重做及 Ctrl+Z、Ctrl+Y 支持批注与文档操作。文本输入框内保留文字输入的撤销。文档快照保留最近 20 次、目标内存上限 128 MB；单次操作超过上限时保留该操作。关闭文档后撤销历史清空，草稿恢复保留文件内容，不恢复撤销栈。文档操作会把此前批注写入该历史快照，先完成当前批注后再进行页面操作。
- “编辑历史”显示修改名称、页码范围、应用/撤销状态与当前批注。保存和另存为之前可以检查文档修改；工具箱导出前显示操作、页码、文字和章节数量。
- 搜索、大纲、视图模式、工具箱和页面编辑按钮支持再次点击关闭。视图模式与统一导航侧栏互斥。

## 阅读与本地处理

- **搜索上下文**：每条结果显示前后文字与关键词高亮，点击定位具体命中；支持最近搜索词。列表最多显示前 300 处，上下命中按钮仍遍历全部结果。无命中时可进入 OCR。
- **树形大纲编辑**：工具箱“页面 → 编辑 PDF 大纲”直接修改标题与页码；选择把手后调整层级、绑定当前页、添加或删除章节；拖动整段分支。自动识别按字号和章节编号生成可编辑草稿，需要人工检查，扫描页先 OCR。
- **页面侧栏**：勾选页码多选，拖动卡片重排或移动选中页面；可提取、删除、旋转和导出排序。提取和导出排序生成副本；删除、旋转和应用排序在当前文档形成可撤销草稿。
- **批注摘录**：导航“批注”显示包含未保存修改的快照，可按内容、类型和颜色筛选，导出 Markdown 或 Word；高亮、下划线等同时提取所在区域文字。原文提取受文字层、框选范围和权限影响。
- **图片原色与配色收藏**：视图模式可保留嵌入位图的原色、调节 50%–150% 亮度/对比度，收藏双色配色。图片区域使用原页面像素叠加，矢量插图仍参与颜色映射；整页扫描图保留原色时，整页图像也保持原色。阅读滤镜不影响保存和打印。
- **草稿与会话恢复**：修改后约 3 秒空闲、及每 15 秒尝试备份；首页提示恢复未正常关闭的会话，或删除备份。正常退出后可“恢复上次标签”。恢复草稿保留未保存标记；原文件变化或已在打开时，草稿成为独立文档，保存需另选文件。备份是本机完整 PDF 副本，不上传、不改写源文件，最后一次备份之后的修改仍可能丢失。
- **工具分类与任务控制**：工具箱按转换、页面、编辑、安全、处理分组。批量任务显示进度，支持取消、失败后继续与重试失败项；同名结果添加数字后缀。取消保留已输出副本；取消发生在导出对话框阶段时，请同时取消该对话框。
- **印章库**：文字与图片印章可保存到本机重复使用，提供日期章。图片印章在保存入库时复制到应用数据目录；可删除库中条目。
- **扫描页优化**：轻微文字页纠偏（±5°）、手动 90° 旋转、浅色背景清理、灰度，以及重新 OCR。按 200 DPI 重建选中页面，原页面对象和批注外观会栅格化；照片、彩色图表宜关闭背景清理。
- **比较**：并排阅读支持页差对齐；另可导出 96 DPI 图像差异报告，红色标记差异像素。一次最多 200 页，按左上角对齐，版式移动与抗锯齿会产生差异。

## 本地工具箱

打开 PDF 后顶部显示 PDF 工具栏（首页与 Markdown 标签不显示）。工具栏“搜索”打开全文搜索侧栏，可看命中结果、前后跳转、区分大小写和全词匹配。“大纲”打开统一导航面板，提供目录筛选与展开折叠、阅读书签、1/2 列缩略图和批注列表。阅读书签保存在本机；“编辑目录”可以将标题、页码、层级及顺序写入导出 PDF。

“视图模式 → 更多颜色模式”提供 15 套双色预设，加上原来的 4 种模式共 19 种。也可自定义背景和文字颜色，按文档记忆。

“工具箱”提供以下本地操作，所有编辑与处理均导出新副本，不直接覆盖正在打开的源文件；源文档未保存批注会一起进入处理副本，但源标签仍保留其未保存状态。

- 转换 PDF 为 DOCX、XLSX、PPTX、PNG、JPEG、SVG、HTML、TXT、CSV。DOCX 采用文本与图片提取，XLSX 采用表格识别/逐行文本，PPTX 为整页图像；复杂版式、原字体和公式不保证保真。
- 从现代 Office、图片、TXT/HTML、EPUB/XPS/CBZ/SVG 创建 PDF。Office 采用内容重排，原分页与复杂版式可能变化。
- 合并、拆分、提取、删除、重排、复制页面，插入空白页，永久旋转和 CropBox 裁剪。
- 对象/流/字体压缩，可选图像降采样和 JPEG 质量；如果不能变小则保留原始数据。
- 本地简体中文与英文 OCR。默认跳过已有文本的页面；可强制重识别。识别页按 200 DPI 图像输出，需要复核文字。
- 框选区域替换原文、永久涂黑、文字/图片/PDF 页面印章、水印、页码、图形、标准下划线/删除线/高亮、创建文本或复选框字段、扁平化批注与表单。
- AES-256 加密、打开与管理密码、打印/复制/编辑权限；移除限制须输入管理密码。权限由阅读器遵守，不能替代打开密码的保密作用。
- 两个已打开文档并排比较，支持同步页码；另可导出逐页文字差异 HTML 报告。图像差异没有自动标记。
- 打开独立窗口阅读磁盘上的 PDF。先保存当前批注，再点“另一个窗口”。
- 转换、压缩、OCR、扫描优化、加密解密、扁平化、文字印章、水印与页码支持批量处理全部已打开文档。同名输出添加数字后缀；逐项失败后继续，可重试失败项。

编辑预览按 PDF 文件原始方向显示，拖动框选区域或输入左/上/右/下百分比。相同相对区域应用到指定页码。页码可写 `1-3,5`；重排可写 `3,1-2,2`；留空表示全部。页码印章使用 `{page}`、`{total}` 占位符。

永久涂黑会删除区域内容并清理元数据、附件、脚本，同时扁平化批注与表单。CropBox 只隐藏页外内容，不能用于删除敏感信息。文字替换采用删除区域原文后写入新文字，不提供保持原字体的 Word 式编辑。签名与印章是可视内容，尚未提供证书数字签名和验证。

单文件处理目前限 512 MB；单任务限 15 分钟。没有会员次数配额。处理使用系统临时目录，正常结束或失败后会清理；系统崩溃或强制结束进程可能留下临时文件。批量输出在任务中途失败时，已经生成的副本保留在输出目录。

## 0.2.0 视图模式

打开 PDF 后，点击 PDF 工具栏右侧的“视图”。

- **单页 / 双页**：切换页面排列；双页时可以启用“封面单独显示”，从第 2–3 页开始配对。
- **垂直滚动**：开启时连续向下阅读，关闭时按单页或一组双页翻页，可用阅读器页码与翻页按钮导航。
- **颜色模式**：日间、夜间、护眼与灰度。颜色滤镜作用于原页面和批注，包括图片；不会改写 PDF，也不影响打印颜色。界面深色/浅色由标题栏右侧的月亮/太阳按钮单独控制。
- **重新排布**：提取当前页文字，自动换行并提供 14–36px 字号、上一页与下一页、退出按钮。保留可复制的文字，不保留图表、原版式和批注，多栏文字顺序取决于 PDF 的文本结构。没有文本的扫描页会提示需要 OCR。搜索时会返回原页面视图。
- **顺时针旋转**：每次旋转 90°。**缩略图**：打开或关闭页面缩略图栏。
- **裁剪页面**：设置上、右、下、左各 0–40% 的阅读边距，隐藏本文件所有页面的相应边缘；可点击“恢复完整页面”。这是阅读遮罩，页面占用的滚动空间不变，不会永久裁掉 PDF 内容，保存和打印仍是完整页面。
- **全屏**：切换全屏，也可用 F11；Esc 退出全屏（视图面板打开时，先关闭面板）。

页面排列、滚动模式、页面颜色、裁剪边距、旋转、文字重排状态和字号按文件记忆。不同标签有各自的设置。重排模式下页面排列、旋转、缩略图和裁剪暂不可操作，退出后恢复原页面工具。

常用快捷键：Ctrl+O 打开；Ctrl+F 搜索；Ctrl+S 保存；Ctrl+Shift+S 另存为；Ctrl+Tab / Ctrl+Shift+Tab 切换标签；Ctrl+1–9 选择标签；Ctrl+W 关闭；Ctrl+Z / Ctrl+Y 撤销/重做；F11 全屏。

文档数据与引擎资源都在本地处理，程序不需要联网；只有启用 AI 协作并发送消息时，才会连接你配置的 AI 服务。阅读记录保存在 Windows 用户应用数据目录的 `qingye-pdf/reading-state.json`（以 Electron 实际的 userData 目录为准）。便携版指无需安装，阅读记录仍按用户保存。关闭有未保存批注的文档会询问保存、不保存或取消。

## 当前范围

这是独立实现的阅读器，不包含 Xodo 安装文件。没有将 Xodo 的付费功能转换为免费功能。

尚未实现完整高保真 Office 双向转换、保持原字体的逐字符编辑、复杂表单设计、证书数字签名、PDF/A 转换与验证、阅读器内覆盖比较与差异跳转或云同步。纯扫描 PDF 没有文本层时，需要先执行 OCR 再搜索。已有数字签名 PDF 编辑或保存修改后，需要重新检查其签名状态。

高亮、文本和墨迹已做保存/重开的集成验证；中文 PDF 的显示取决于原文件字体与字符映射。中文文本框在不同阅读器中的字体外观仍需进一步验证。评论、图片、签名和打印保留引擎界面，但尚未完成各项跨阅读器测试。本版本未进行代码签名。

## 构建

使用 Node.js 24 或兼容版本，在 Windows 中运行：

```powershell
npm.cmd ci --no-audit --no-fund
npm.cmd run prepare:pdfjs
npm.cmd run build:backend
npm.cmd test
npm.cmd run smoke
npm.cmd run dist
```

`npm.cmd start` 运行开发版本。`npm.cmd run dist` 输出便携 EXE 和 `win-unpacked` 目录；`npm.cmd run dist:all` 同时输出便携版与安装版。构建后端需要 Python 3.12+；构建脚本创建隔离虚拟环境，安装版本锁定依赖并用 PyInstaller 生成处理引擎。最终用户不需要安装 Python。开发代码通过主进程授权的临时文件启动后端，处理引擎不提供网络接口。

交付前先运行 `python scripts/package-source.py` 生成匹配源码，再运行 `npm.cmd run deliver`。后者把便携包、源码/依赖源码、当前说明、功能范围、变更记录与版本许可文件同步到项目旁的 `output/qingye-pdf`；可用 `npm.cmd run deliver -- <目标目录>` 指定目录。脚本检查下载指引版本并生成 SHA256 清单，避免忘记更新随包文档。它只准备本地文件，不对外发布。

构建不需要 Xodo 或商业 PDF SDK。阅读引擎固定为 PDF.js 6.3.289，Electron 固定为 44.4.5，编辑引擎固定为 PyMuPDF/MuPDF 1.28.2。源码包附带 PDF.js 与 OCR 离线资源；`backend/requirements-lock.txt` 记录全部后端版本。依赖源码包包含匹配版本源码，来源与哈希见 `third-party-source/sources.json`。运行 `python scripts/prepare-sources.py` 可准备匹配源码；`python scripts/package-source.py` 打包应用和依赖源码。

这不代替真实用户对大量复杂 PDF、触控、压感、打印机、无障碍和其他阅读器的验收。保存采用同目录临时文件、内容冲突检查和文件替换，不能保证阻止其他进程在检查与替换之间的极短时间内修改目标。

## 项目结构

`main.cjs` 管理窗口、受限本地资源协议、文件权限、对话框和记录；`preload.cjs` 提供有限 IPC；`core.cjs` 实现保存和示例 PDF；`offline.cjs` 管理临时处理任务；`backend/worker.py` 是本地处理引擎；`ui` 是独立界面；`vendor/pdfjs` 保留 Mozilla 阅读引擎、资源与许可证。

PDF.js 的 viewer HTML 修改仅涉及标题和独立样式表引用，记录在 `vendor/pdfjs/QINGYE-MODIFICATIONS.md`。应用使用固定版本的阅读器内部编辑器接口，在升级 PDF.js 时必须重跑集成验证。
