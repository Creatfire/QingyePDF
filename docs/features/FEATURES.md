# 青页 PDF 0.21.0 功能范围

当前交付目标是 Windows 10 / 11 x64 的 0.21.0 安装版和安装目录 ZIP，以及 macOS（Apple 芯片、Intel）的 DMG。Android 代码保留在仓库中，但本版未重新构建或验收；Android 项目版本为 0.18.0，不能据此宣称与 Windows 功能一致。操作说明见 [用户手册](../guide/USER-GUIDE.md)，本版验证与未测项见 [交接记录](../releases/HANDOFF.md)。

## 能力与限制

本清单以用户提供的 Windows Xodo 截图为主要对照，参考 Xodo 官方 Windows 功能介绍和本地 PDF 操作说明。Xodo Windows Reader 与 Xodo PDF Studio 是不同产品；此处不把两个产品的所有能力混为已经实现。本软件独立使用开源引擎实现，不复制或解锁 Xodo 安装包。

参考：[Xodo Windows 功能介绍](https://xodo.com/about)、[官方编辑与页面操作说明](https://feedback.xodo.com/support/solutions/articles/35000251312-editing-and-manipulating-pdfs)、[官方功能与工具说明](https://feedback.xodo.com/support/solutions/articles/35000251487-ribbon-toolbar)。

| 截图 / 用户要求 | 本版本实现 | 范围 |
|---|---|---|
| 更多颜色与自定义 | 19 种模式、自定义、收藏、亮度/对比度、保留嵌入位图原色 | 不改变保存和打印；矢量插图仍参与颜色映射 |
| 搜索 | 全文搜索栏、命中上下文与高亮、定位具体结果、历史词、大小写与全词选项 | 列表前 300 处；扫描页先 OCR |
| 大纲 | 层级目录、筛选、展开/折叠；树形直接编辑、拖动分支、调整层级、自动标题识别 | 导出新副本；自动识别结果需复核 |
| 书签、缩略图、批注列表 | 本机书签、1/2 列缩略图；批注与摘录面板：卡片、关键词 / 类型 / 颜色 / 标签 / 页码 / 摘录状态筛选，批量改色、标签、删除、导出 Word / Markdown，卡片与页面选择联动 | 标签保存在 PDF 的私有键中，其他阅读器不显示；“已摘录”按笔记中的链接位置或引文判断 |
| 页面管理 | 缩略图网格：多选、拖动排序、旋转、复制、删除、空白页、插入其他 PDF（拖入文件），最终页序预览，一次应用一步撤销；按书签 / 每 N 页 / 范围 / 选中页拆分；导出选中页、提取图片 | 拆分作用于已应用的文档；插入一次最多 20 个 PDF；书签与批注随页面移动，被删除页面的书签会去掉 |
| 任务与工作区 | 任务中心（进度、结果数量、输出位置、取消、重试、排队、近期记录）；修改文档的任务绑定开始时的版本；工作区（文档组、笔记模式搭配、当前标签、重新定位）与固定文档 | 近期任务只在本窗口记录；工作区按路径记住文件，未保存的新文档不能加入 |
| Unlimited Document Actions | 全部已实现工具直接开放 | 无会员次数配额；单文件处理当前限 512 MB，单任务限 15 分钟 |
| Bulk Document Processing | 转换、压缩、OCR、扫描优化、加密解密、扁平化、文字印章、水印、页码批量处理；进度、取消、失败继续/重试 | 同名输出添加后缀；已输出副本保留 |
| Advanced Document Compression | 对象清理、流压缩、字体子集化、可选图像降采样和 JPEG 质量 | 有损模式会影响图像质量；不能缩小时保留原数据 |
| Side by Side PDF Compare | 并排阅读、页差对齐、同步页码与缩放；阅读器内文字差异高亮（删除标红、新增标绿）与上一处 / 下一处跳转；文字或图像差异 HTML 报告 | 阅读器内比较只比文字层（中文按字、英文按词），最多 300 页；差异过多的页面标为“未完成比较”；扫描件需先 OCR；HTML 报告的图像按 96 DPI 左上角对齐，最多 200 页 |
| PDF to Office Conversion | DOCX、XLSX、PPTX | DOCX 为文本/图片；XLSX 为识别表格/逐行文本；PPTX 为页面图像（按所选 DPI，横竖页保持比例） |
| PDF to Images | PNG、JPEG、SVG；多页输出 ZIP | PNG/JPEG 支持 36–300 DPI，单页最多 4000 万像素 |
| PDF to Files / HTML | TXT、CSV、HTML | 文本层提取；HTML 可保留页面定位和内嵌图像 |
| Office / Images to PDF | 直接打开 DOC/DOCX、XLS/XLSX/CSV、PPT/PPTX、ODT/ODS/ODP、RTF、WPS 文件（LibreOffice，首次使用时询问并下载，保留版式，有进度与取消）；工具箱和文档转换中心的 Office → PDF 默认同样走 LibreOffice（可选内容重排）；工具箱转换 PNG/JPEG/BMP/TIFF/WebP、TXT/HTML/EPUB/XPS/CBZ/SVG | 首次转换约 5–8 秒，预热后 1–3 秒；版式取决于 LibreOffice 对文件的兼容程度，缺少的字体会被替换 |
| 编辑 | 区域原文替换、图形、标准高亮/下划线/删除线、创建文本和复选框表单 | 不提供原字体保持的逐字符编辑、段落自动重排或复杂表单逻辑 |
| 页面编辑 | 合并、拆分、提取、删除、重排、复制、空白页、永久旋转、CropBox 裁剪 | 输出新副本；CropBox 不删除区域外内容 |
| PDF Redaction | 删除区域文字、图像、相交图形；清理元数据、附件、脚本 | 移除与涂黑区域相交的批注、表单和链接；以新文件重写，不是覆盖黑色矩形；应复核相邻内容 |
| Unlimited image, page and text stamping | 文字、图片、PDF 页面印章；日期章、常用文字/图片印章库；水印和页码；图片印章默认保持比例居中，可选拉伸填满 | 库最多 100 项，页面印章保留矢量；不是证书数字签名 |
| 加密与安全 | AES-256 打开密码、管理密码、打印/复制/编辑权限；授权移除密码 | 移除加密要求管理密码，不破解密码；权限取决于阅读器遵守 |
| Multi-Window PDF Viewing | 工具箱“另一个窗口” | 保存当前批注后，独立窗口打开磁盘版本；外部修改冲突检查仍有效 |
| 本地 OCR | 简体中文 + 英文，无联网；只补透明文字层，保留原页面与批注；疑似混合页（只有页码等少量文字的扫描页）也识别；可只识别框选区域 | 重新生成页面图像请用扫描件纠偏；准确率与原始图像相关，重要内容请复核 |
| 扫描优化 | ±5° 文本页纠偏、旋转、浅色背景清理、灰度、重新 OCR | 200 DPI 栅格化重建；不提供照片透视校正或自动去黑边 |
| 备份与恢复 | 本地草稿、崩溃会话恢复、上次标签恢复 | 原文件变化时恢复为独立文档；最后一次备份后修改可能丢失 |
| Windows 集成 | 安装版与安装目录 ZIP；安装时可选桌面快捷方式和 PDF / Markdown / Office 的“打开方式”；设置中随时修改（当前用户，无需管理员）；卸载时可选择保留用户数据；手动检查更新 | Windows 不允许程序直接设置默认应用，需用户在“打开方式”或系统设置中确认；没有自动更新 |
| 原有阅读批注 | 多标签、打印、文字/墨迹/高亮/可视签名、图片、评论、阅读记忆、视图面板 | 评论/图片/可视签名/打印尚未完成全部跨阅读器和硬件验收 |
| Cross-Platform Access / 云同步 | 未加入 | 当前交付 Windows x64 EXE；账号、云端协作、AI 云服务和跨端账户访问不在本地范围 |

尚未实现或尚未达到 Xodo 对等效果：高保真 Office 双向转换、保持原字体的所见即所得原文/图像编辑、证书数字签名与验证、PDF/A 转换与验证、复杂表单设计、图像层面的覆盖比较、测量工具、手绘与多边形批注的拖动、扫描件自动去黑边与 90° 方向识别（页面内容的自动裁剪已在 0.14 实现）、完整无障碍和触控压感验收。多窗口已实现，跨窗口最近记录仍可能以后写入的版本为准。本版本覆盖截图列出的主要本地类别，但不能宣称“与 Xodo 所有功能完全等同”。
