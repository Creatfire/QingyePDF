# 青页 PDF 0.9.3 修复版 1

本次基于完整的 A/B/C/D 正式报告、D 专项补充、E 轮收尾总结、R02/R04/R05/R06 定位文档及各轮补测结果，修复六项软件缺陷与 D-001。版本号保留 0.9.3，包内 buildRevision 为 fix1；应使用新的 SHA256 区分原测试包。原 exe/源码归档保存在交付目录 before-fix。

| 编号 | 修复 |
|---|---|
| BUG-093-04：长输入路径整应用退出 | 长 cwd 不再传给子进程；长路径输入在短临时目录执行，使用绝对资源目录，并解析相对选项文件。子进程输出/错误管道也挂接错误处理器，转换故障归入任务错误 |
| BUG-093-02：长输出目录 mkdtemp 失败 | 转换临时工作目录使用系统短路径；输出在目标目录采用短临时文件名及 Windows 扩展路径提交，实际支持长输出路径。排他发布仍拒绝覆盖并发创建的文件 |
| BUG-093-06：关窗进程滞留与临时目录泄漏 | 关闭窗口/退出前取消转换，并等待子进程、排版窗口和临时文件清理完成。PDF 排版可随任务取消销毁隐藏窗口；清理结束前不启动 Chromium 退出 |
| BUG-093-01：Esc 关闭转换结果窗口 | 捕获 Escape 按键自行取消任务；对不可取消的 dialog cancel 事件保留结果窗口，任务取消与结果可见性分别处理 |
| BUG-093-05：隐式 AI 工具误读新文档 | 发起提问时记录目标文档 id，本轮隐式工具固定使用这个 id；关闭后报错，切换标签不会改变目标。显式指定其他文档与列出文档仍正常 |
| BUG-093-03：合并说明漏译 | 添加英文、繁中、日文、韩文对应短句键，并重建字典 |
| D-001：引用点击后回到第一页 | 追踪确认点击与 followReference 已执行，后续 ResizeObserver/标签缩放用旧 PDF.js 位置拉回第一页。两个缩放入口统一保留最新页码；冒烟同时等待解析器、页面及离屏绘制就绪 |

历史对话重新生成时，仅在新一轮开始可以按保存的原路径匹配已经打开的文档，兼容重启后的新标签 ID；正在执行的工具不作路径回退，关闭或重开原文仍会让旧轮工具报错。

## 验证入口

```powershell
npm.cmd test
npm.cmd run test:fixes
npm.cmd run basic
node node_modules/electron/cli.js . --fix-smoke
node node_modules/electron/cli.js . --fix-close-smoke
```

- fixes093.test.cjs：长输入/长输出三组合、相对资源与模板、并发文件保护、AI 隐式目标关闭/切换、退出等待清理。
- fix093-smoke.cjs：真实 Electron Escape、不可取消 cancel 回退、取消输出保护、英文文案、完整模拟 AI 请求中关闭原 PDF 后工具报错。
- fix-close093-smoke.cjs：正在转换时真实 BrowserWindow 关闭流程，完成清理后进程退出。
- basic093-smoke.cjs：引用实际跳转；失败会保存调用与页码/滚动位置追踪，避免以无原因重跑掩盖问题。

本次保留并解释原报告中的假失败与边界：自定义模板缺目录占位符不是应用缺陷；负 viewBox 是上游 Ink 重载时的控制台噪声，原测试确认可见内容正常，未改动上游引擎。真实 AI 服务、125% DPI、多显示器/远程桌面、非 NTFS/磁盘不足、默认应用注册链路、打印出纸与大文件全量另存等原报告未覆盖范围，仍不能视为通过。
